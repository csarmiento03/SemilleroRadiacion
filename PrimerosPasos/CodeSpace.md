## 🚀 Recommended setup: GitHub Codespaces

If you are using Windows or do not want to install Docker locally,
you can run the complete workshop directly from GitHub Codespaces.

### 1. Open the Codespace

1. Open this repository on GitHub.
2. Click **Code**.
3. Select **Codespaces**.
4. Click **...**
5. Click **New with options**
6. In machine type choose your highest option (for example 4-core)
7. Click create codespace

No local installation of Linux, Docker, ARTI or MEIGA is required.

The default GitHub Codespace already includes:
- Linux
- Docker
- Python
- Git


### 2. Download ARTI and MEIGA
-In the codespace's terminal:

ARTI:

docker pull rmartinezmaple/arti_lidera:latest

MEIGA:

docker pull rmartinezmaple/meiga-school:3.4.1-g4gro-viewer
